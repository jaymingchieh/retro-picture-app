# 🎬 Retro Studio ·「如果我活在80年代」AI 復古照片指令產生器

一個**純前端**的復古照片小工具，跟上爆紅的 ChatGPT
**「如果我活在80年代會是什麼樣子？」** AI 生圖風潮。

點一點就能組合出一段可直接貼到 ChatGPT 的完美指令，再上傳照片套用
80 年代底片濾鏡，先感受那個蓬鬆大捲髮、濃眉紅唇、墊肩西裝的年代。

> 發想來源：ChatGPT「如果我活在80年代」(1980s AI Photo Trend) 復古照片風潮。

---

## ✨ 功能

- **🎛️ 指令產生器**
  - 選擇年代（1970s / 1980s / 1990s）、情境角色（亞洲都會女性、香港電影女主角、東京都會女性、復古寫真館…）、妝容（眉／眼影／腮紅／唇）、髮型、服裝、底片風格。
  - 即時組合出完整的**中文／英文**指令，內容依照原始風潮的進階範例設計。
  - 可勾選「保留主要五官與臉型特徵」「避免現代感元素」。
  - **一鍵複製**，直接貼到 ChatGPT。
- **📷 80 年代濾鏡預覽**
  - 上傳照片 → 套用暖黃褪色調、底片顆粒、暈影、復古日期戳記 → 下載。
  - 5 種濾鏡風格 + 強度／顆粒／暈影可調。
  - 照片**完全在你的瀏覽器**處理，不會上傳到任何伺服器。
- **🕹️ 80 年代美學介面**：霓虹配色、grid 地平線、掃描線與復古字型。

---

## 🚀 如何使用

1. **選風格**：在指令產生器挑選年代、情境、妝髮與底片質感。
2. **複製指令**：按「一鍵複製」。
3. **貼到 ChatGPT**：貼上指令，並上傳一張五官清楚、光線充足、臉部沒有過度遮擋的個人照。
4. **微調**：換情境（例如「80年代香港電影女主角」）或調整妝髮再生成一次。
5. **玩濾鏡**：也可以在本站上傳照片，直接套用復古濾鏡下載。

> 💡 80 年代妝髮關鍵：濃眉、有存在感的眼影腮紅、紅唇，以及蓬鬆的大波浪髮型。

## 💻 本地執行

不需要任何 build 步驟或套件，直接用瀏覽器開啟即可。

```bash
# 方法一：直接打開
open index.html          # macOS
# 或在檔案總管雙擊 index.html

# 方法二：起一個簡單的本機伺服器（建議，避免瀏覽器對本地檔案的限制）
python3 -m http.server 8000
# 然後開啟 http://localhost:8000
```

## 🌐 部署到 GitHub Pages

這是純靜態網站，可直接部署：

1. 到 GitHub repo → **Settings → Pages**。
2. **Source** 選 **Deploy from a branch**。
3. 選擇分支（例如 `main`）與 `/ (root)` 資料夾，儲存。
4. 稍等片刻，即可透過
   `https://<你的帳號>.github.io/retro-picture-app/` 開啟。

（本專案已包含 `.nojekyll`，確保靜態檔案原樣發佈。）
