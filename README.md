# 📸 Retro Cam · 復古相機

一個**可安裝的 PWA** 韓系 Y2K 復古相機。打開就能用手機相機**即時拍照**，
套上 CCD 發色、底片顆粒、漏光與復古日期戳記，靈感來自
[DICA Seoul（迪卡首爾）](https://apps.apple.com/tw/app/id6763706077) 那類 digicam App。

> 照片**完全在你的裝置上**處理與保存（IndexedDB），不會上傳到任何伺服器。

---

## ✨ 功能

- **📷 即時相機**：`getUserMedia` 開啟相機即時預覽，支援前／後鏡頭切換（自拍自動鏡像）。
- **🎞️ 復古濾鏡**：9 組風格 — CCD 清晰、暖陽底片、冷調 Y2K、泛黃回憶、**泛黃老照片**、**拍立得（白框）**、黑白底片、夜間閃燈、原色，可調**濾鏡強度**。
  - 疊加**底片顆粒、暈影、漏光、暖／冷色調**，拍照時自動燒上**復古日期戳記**；拍立得會加上白邊並把日期印在下方白框。
- **📤 上傳既有照片**：從手機相簿選照片 → 套用同一套復古濾鏡（即時預覽、可調強度）→ 儲存／下載；四格模式選 4 張可直接組成復古四格。照片一樣只在瀏覽器處理。
- **✨ 漏光／光斑貼圖**：可再疊一層獨立的漏光光斑（暖角漏光、彩虹光斑、陽光光暈、復古紅光、金色光塵），程序繪製、與濾鏡獨立，拍照／上傳／四格都會套上。
- **🧩 四格拼貼（인생네컷風）**：切到「四格拼貼」模式，3-2-1 倒數依序拍 4 張，自動合成復古四格。
  - 兩種版面：**直式相條**與 **2×2 格**；可選**相框顏色**（奶油／白／黑／珊瑚），頁尾自動加上標題與日期。每格都套用你當下選的濾鏡。
- **🖼️ 本機相簿**：拍完存進 IndexedDB，可瀏覽、檢視、下載、刪除，離線也能看。
- **📲 可安裝 PWA**：加到手機主畫面像原生 App 一樣全螢幕開啟，Service Worker 提供離線快取。
- **🎀 Y2K digicam 介面**：奶油＋珊瑚＋薄荷配色、觀景窗框、快門鈕、REC 與日期顯示。

## 🚀 使用方式

1. 用手機瀏覽器開啟網站（**必須是 HTTPS**，相機才能啟用；GitHub Pages 符合）。
2. 點「開啟相機」，允許相機權限。
3. 選濾鏡、調強度，按中間快門鈕拍照。
4. 左下縮圖進入相簿，可下載或刪除。
5. **上傳既有照片**：點右上「⬆︎ 上傳」選相簿裡的照片 → 套濾鏡 → 存檔／下載（四格模式選 4 張可直接組四格）。
6. （選用）用瀏覽器選單「加入主畫面」把它裝成 App。

> 📌 相機需要**安全來源**（HTTPS 或 `localhost`）。用 `file://` 直接開會無法啟用相機。

## 💻 本地執行

純靜態，無需 build。但相機需要安全來源，請用本機伺服器（`localhost` 視為安全）：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

若要在**手機實機**測試相機，手機需連到 `https://`。可用如 `ngrok http 8000`
之類的工具開一條 HTTPS 通道，或直接部署到 GitHub Pages。

---

## 🌐 部署到 GitHub Pages

1. GitHub repo → **Settings → Pages**。
2. **Source** → **Deploy from a branch**，選分支與 `/ (root)`，儲存。
3. 開啟 `https://<你的帳號>.github.io/retro-picture-app/`（HTTPS，相機可用）。

已包含 `.nojekyll`，確保 `sw.js` 等檔案原樣發佈。

## 🏗️ 架構

純用戶端 PWA，模組化 vanilla JS，無框架、無後端：

```
retro-picture-app/
├── index.html              # App shell
├── manifest.webmanifest    # PWA manifest（可安裝）
├── sw.js                   # Service Worker（離線快取）
├── css/
│   └── styles.css          # Y2K digicam UI
├── js/
│   ├── camera.js           # getUserMedia 相機控制（前後鏡頭）
│   ├── filters.js          # 濾鏡引擎（色調 + 顆粒/暈影/漏光/日期 + 拍立得白框）
│   ├── leaks.js            # 漏光／光斑疊加層（程序繪製）
│   ├── collage.js          # 四格拼貼合成（相條 / 2×2、相框、頁尾）
│   ├── db.js               # IndexedDB 本機相簿
│   └── app.js              # 主流程（預覽迴圈、拍照、四格、相簿、安裝）
├── icons/                  # PWA 圖示（192/512/apple-touch）
├── .nojekyll
└── README.md
```

**為什麼是 PWA 而非純靜態頁或原生 App？**
即時相機需要 `getUserMedia` + 安全來源，且使用者期待「像 App 一樣安裝、離線可用」，
所以用 PWA（manifest + service worker）最合適；同時免去原生 App 的上架流程，
一份程式碼即可在 iOS / Android / 桌面安裝使用。

## 🔒 隱私

- 沒有後端、沒有帳號、沒有追蹤、沒有網路上傳。
- 相機畫面與拍下的照片只存在你的瀏覽器（IndexedDB），清除瀏覽器資料即全部移除。
